Factory Inventory Management System — Architecture

A full-stack demo application: Vue 3 frontend, Python FastAPI backend, and JSON-backed in-memory mock data. No database, no authentication backend — designed for workshop / demo use.

Tech Stack

Frontend

Vue 3 + Vite

  • Composition API
  • vue-router 4
  • axios for HTTP
  • Custom SVG charts, CSS Grid layouts
localhost:3000
Backend

Python FastAPI

  • Pydantic models for validation
  • Uvicorn ASGI server
  • CORS middleware (open, demo-only)
  • Managed with uv
localhost:8001
Data

In-Memory Mock Data

  • JSON files in server/data/
  • Loaded once at startup by mock_data.py
  • No persistence layer / database
flat files

Key Patterns & API Surface

Key Patterns

  • Filter system: 4 global filters (Time Period, Warehouse, Category, Order Status) applied consistently across views via query params.
  • Reactivity: Raw API data lives in refs (e.g. allOrders, inventoryItems); derived values are computed properties.
  • Data flow direction: Vue filters → api.js → FastAPI → in-memory filtering → Pydantic validation → computed properties.
  • No database: All state resets on backend restart; JSON files are the source of truth.
